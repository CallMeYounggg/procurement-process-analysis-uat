📌 Project Overview

# Project Objective

Analyze and document a Procure-to-Pay (P2P) procurement workflow and develop a structured User Acceptance Testing (UAT) framework to validate business requirements, identify system and process defects, and recommend improvements for ERP procurement operations.

# Project Type

Portfolio Simulation Projects

# Business Context

**Organization**: ABC Healthcare Group 

**Industry**: Healthcare 

**Department**: Procurement & Finance 

**System**: ERP Procurement System 

**Process**: Procure-to-Pay (P2P)

# Project Scope

This project focuses on the end-to-end Procure-to-Pay process, covering Purchase Requisition, Purchase Order, Goods Receipt, Invoice Verification and three-way matching.

# Key Activities

- Business requirements analysis
- P2P process documentation
- Process flow mapping
- UAT planning
- UAT test case development
- UAT execution simulation
- Defect identification and tracking
- Defect retesting
- Process improvement recommendations
- UAT reporting
